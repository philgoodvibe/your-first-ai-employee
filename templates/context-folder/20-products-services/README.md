# Products & Services - [BUSINESS NAME]

> **Drop into this folder:** sales pages, pricing PDFs, product specs, service agreements, FAQ docs, comparison tables, value-prop write-ups. Everything that explains what we sell.

## Format suggestion

One file per offer. Name them: `01-[offer-slug].md`, `02-[offer-slug].md`, etc.

Each offer file should answer:
1. What does the customer get?
2. What problem does it solve?
3. Who is it for? Who is it NOT for?
4. What's the price and how do they buy?
5. What's the typical outcome?
6. What objections come up and how do we handle them?
