# Customers - [BUSINESS NAME]

> **Drop into this folder:** ICP write-ups, customer interview transcripts, testimonials, case studies, support-ticket patterns, churn analyses, customer surveys. The richer this folder, the better your AI employee writes.

## Format suggestion

- `01-icp-current.md` - who we serve today
- `02-customer-language.md` - phrases real customers use when they describe the problem, the buying decision, and the result
- `03-content-non-negotiables.md` - what our content should never do
- `case-studies/` - one file per customer story
- `testimonials/` - one file per quote
- `interview-transcripts/` - one file per interview
- `surveys/` - quantitative data
